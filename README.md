
**JSON to TypeScript Interface Generator** \n
A lightweight React application that converts raw JSON into TypeScript interfaces or types.
\n\n
**Features** \n
1. Convert JSON to TypeScript Interfaces or Types
2. Supports nested objects & arrays
3. Automatically generates PascalCase type names
4. Handles invalid object keys safely
5. Copy output to clipboard
6. Sample JSON insertionl
7. Error handling for invalid JSON
\n\n
**Tech Stack** \n
React + TypeScript
Vite
Sonner
CSS
\n\n
**Installation** \n
1. Clone the repository:
   git clone https://github.com/riyathakker/type-generator.git
2. Navigate to project folder:
   cd type-generator
3. Install dependencies:
   npm install
4. Start development server:
   npm run dev
\n\n
**Usage** \n
Paste your JSON in the JSON Input field
Enter the desired Type/Interface Name
Select output style
Click Generate
Click Copy to copy output to clipboard
