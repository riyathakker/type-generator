# JSON to TypeScript Interface Generator

A lightweight React application that converts raw JSON into TypeScript interfaces or types.

---

## Features

- Convert JSON to TypeScript Interfaces or Types
- Supports nested objects & arrays
- Automatically generates PascalCase type names
- Handles invalid object keys safely
- Copy output to clipboard
- Sample JSON insertion
- Error handling for invalid JSON

---

## Tech Stack

- React + TypeScript
- Vite
- Sonner (Toast notifications)
- CSS

---

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/riyathakker/type-generator.git
```

### 2. Navigate to project folder

```bash
cd type-generator
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```
---

## Usage

- Paste your JSON in the JSON Input field
- Enter the desired Type/Interface Name
- Select output style
- Click Generate
- Click Copy to copy output to clipboard
